## What is a Data Structure?

Aik Data Structure aik khaas way hota hey data ko computer ki memory mey arange/organize or store karney ka takey usay efficiently access or update kia ja sakey.

### Type of Data Structure?

There are two types of data structures, linear and non-linear.

#### Linear Data Structure

Aisa data structure jismein data ek sequence mein hota hai. Ye sequence memory mein physically continuous bhi ho sakta hai ya logically connected bhi.

**Examples:** Arrays, Linked Lists, Stacks, and Queues

#### Non-Linear Data Structure

Aisa data structure jismein data hierarchical ya interconnected nodes ke structure mein store hota hai. Ismein elements non-sequential tareeqe se arranged hote hain.

**Examples:** Trees, Graphs

## Algorithm

A set of instructions given to the computer to solve a problem efficiently. The performance of an algorithm can be evaluated based on time and space complexity
