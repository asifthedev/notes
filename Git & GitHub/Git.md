## Git

It's a version control system that is used to track, save, and revert to different versions of the code. It's developed by Linus Torvald.

## GitHub

It's a hosting service for Git Repositories that lets you store your Git repos online in the cloud and enables different developers collaborate on the same project.

## Repositry

A folder or directory where Git stores all of your code and its different versions.

## Initilizing a Git Repo

```git
git init
```

## Checking Status

```git
git status
```

## Git Staging Changes

```git
git add -A
```

or 

```git
git add --all
```

**NOTE**: The command where you use `.` symbol that mean stage only the current directory let if your repo name is a and you in any directory inside if you try to stage your changes using `.` it will only stage changes of the current directory instead of whole repo.

```git
git add .
```
