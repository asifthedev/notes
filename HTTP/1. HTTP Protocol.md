## HTTP Protocol

HTTP is a data communication protocol used to send and receive data between HTTP servers and HTTP clients. *HTTP* is an application-layer protocol.

## HTTP Message

An HTTP message has 3 main parts:

### 1. Request/Response Line

Ager message request message, hey to request line hogin or ager message response message, hey to response line hogi.

Let's look at the request line.

```http
GET /index.html HTTP/1.1 <-- Request Line
```

**HTTP Method**

Kis traha ka action perform karna hey, just to tell the server but semantically k 

**Headers**

1. Empty Line (used to mark the end of HTTP Headers and start of body of the message)

2. Body (Optional)

Here is an example of a request message:

```http
GET /index.html HTTP/1.1 <-- Request Line
Host: www.example.com <-- Start of HTTP Headers
User-Agent: Mozilla/5.0 (Windows NT 10.0)
Accept: text/html
Connection: keep-alive <-- End of HTTP Headers
```

 Here's an other example of HTTP response message:

```http
HTTP/1.1 200 OK <-- Response Line
Date: Tue, 27 Jan 2026 15:00:00 GMT <-- Start of HTTP Headers
Server: Node.js/Express
Content-Type: application/json; charset=utf-8
Content-Length: 78
Connection: keep-alive <-- End of HTTP Headers
                       <-- Empty Line 
{                      <-- Response Body
  "success": true,
  "message": "Data mil gaya hai",
  "data": { "id": 101, "item": "Laptop" }
}
```

### Request Line

It has three parts

1. HTTP Method (Konsa method use ho raha hey)

2. Path (help the server know where to look for request resource)

## HTTP Methods

**GET:** Data retrieve karne ke liye (maslan user ki list dekhna).

**POST:** Naya data create karne ke liye (maslan naya user register karna).

**PUT:** Poore resource ko update karne ke liye.

**PATCH:** Resource ka sirf ek hissa update karne ke liye.

**DELETE:** Data khatam karne ke liye.

## HTTP Status Codes

**100 (Infromational Response):** 

**2xx (Success):** `200 OK`, `201 Created`.

**3xx (Redirection):** `301 Moved Permanently`, `304 Not Modified`.

**4xx (Client Error):** `400 Bad Request`, `401 Unauthorized`, `404 Not Found`.

**5xx (Server Error):** `500 Internal Server Error`, `503 Service Unavailable`

### Idempotency kya hoti hai?

**Idempotent** method wo hota hai jise baar baar call karne se result change na ho.

- **GET, PUT, DELETE** idempotent hai. (Agar aap ek hi file 10 baar delete karein, to wo delete hi rahegi).

- **POST** idempotent nahi hai. (Har baar call karne par naya record ban sakta hai).

### HTTP/1.1 vs HTTP/2

Modern applications mein performance ke liye ye farq jaana zaroori hai:

- **Multiplexing:** HTTP/1.1 mein ek waqt mein ek hi request/response chalta hai (ya limited parallel). HTTP/2 mein ek hi TCP connection par bohat saari requests ek saath (parallel) ja sakti hain.

- **Header Compression:** HTTP/2 mein **HPACK** algorithm use hota hai jo headers ka size kam kar deta hai.

- **Binary Protocol:** HTTP/1.1 text-based hai, jabke HTTP/2 binary format use karta hai jo machine ke liye fast hota hai.

## Statelessness kya hai?

Yani server kuxh yad nahi rakhta, aik dafa woh kisi request ka server kardiya to server bhool jata client kon that or uska status kia hey abhi.

HTTP ek stateless protocol hai, yani server har request ko nayi request samajhta hai. Or har request k pass woh sara data hota hey jo server ko chaye us aik request server karney kelye.
