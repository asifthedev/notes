# HTTP Methods

HTTP methods, jinhe aksar **HTTP verbs** bhi kaha jata hai, actually wo actions hain jo batate hain ke aap server se kya karwana chahte hain.

Jab bhi aap koi request bhejte hain, method ye define karta hai ke aap data mangwa rahe hain, naya data bhej rahe hain, ya purane ko delete kar rahe hain.

### 1. GET

Server se data ya resource mangwanay kelye use hota hai. Yeh ek **Idempotent** method hai, kyunke sirf data read hota hai, server par koi tabdeeli nahi aati.

### 2. POST

Server par naya resource **create** karnay kelye use hota hai (maslan: database mein aik naye user ya book ki entry).

Yeh idempotent nahi hota kyunke har baar request bhejne par naya record ban sakta hai.

### 3. PUT

Mojooda (existing) resource ko **mukammal tor par replace** karnay kelye use hota hai. Agar resource mojood nahi hoga, toh yeh naya create kar dega.

Yeh idempotent hai kyunke ek hi data ko baar baar replace karnay se final result wahi rehta hai.

### 4. PATCH

Jab poora record replace nahi karna ho, balkay sirf **kuch hissa (partial update)** badalna ho, tab PATCH use hota hai.

Agar aapne sirf user ka phone number badalna hai, to PATCH behtar hai bajaye poora object bhejne ke.

### 5. DELETE

Server se kisi makhsoos resource ko **khatam ya destroy** karnay kelye istemaal hota hai.

### 6. HEAD

Yeh bilkul GET ki tarah hai, lekin yeh response mein sirf **HTTP Headers** mangwata hai, actual body (data) nahi.

Yeh check karnay kelye useful hai ke resource ka size kya hai ya woh exist karta bhi hai ya nahi, baghair poora data download kiye.

Simple HEAD method per server apko response Headers send kar deyta hey per response body send nahi karta.

### 7. OPTIONS

Yeh server se uski **capabilities** puchnay kelye hota hai. Maslan, server kaun kaun se methods (GET, POST, etc.) allow kar raha hai, ya koee origin allow karta hey k nahi, ya phir khas Header allow karta hey k nahi.

It used to make a preflight request, a request before the actual request, to ask the server do you support a specific HTTP method, header, or allows the specified origin.
