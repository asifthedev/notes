HTTP protocol waqt ke sath kafi evolve hua hai taake web speed, security, aur efficiency ko behtar banaya ja sake. Har version ne usay pehlay waley version ki drawback ko solve kia ya new capabilities ko introduce karwaya hey.

Let's have look at all the different versions of HTTP are introduced until now.

### HTTP/0.9 (1991) - The One-Line Protocol

Ye sabse pehla aur nihayat sada version tha.

- Is mein sirf **GET** method hota tha.

- Headers ka koi concept nahi tha, sirf raw HTML file mangwai ja sakti thi.

- Server connection foran band kar deta tha file bhejne ke baad.

#### 2. HTTP/1.0 (1996)

Is version ne HTTP ko properly define kiya aur functionalities barhaein.

- **Headers** introduce huye (Content-Type, User-Agent etc).

- GET ke ilawa **POST** aur **HEAD** methods shamil huye.

- Sirf HTML hi nahi, balki images aur doosri files bhi bhejna mumkin hua.

- **Drawback:** Har file ke liye ek naya TCP connection kholna parta tha, jo slow tha.

##### What is TCP?

**TCP (Transmission Control Protocol)** ek connection-oriented protocol hai jo TCP/IP **suite** ki **Transport Layer** mein kaam karta hai. Ye data bhejane se pehle connection pakka karne ke liye **three-way handshake** follow karta hai:

1. **SYN (Synchronize):** Sabse pehle **Client**, server ko ek "SYN" packet bhejta hai. Iska matlab hota hai ke Client connection establish karna chahta hai.

2. **SYN-ACK (Synchronize-Acknowledgment):** Server iska jawab deta hai. Wo kehta hai ke mujhe tumhari request mil gayi hai (ACK) aur main bhi connection ke liye taiyar hoon (SYN).

3. **ACK (Acknowledgment):** Last mein Client phir se server ko message bhejta hai ke "Theek hai, mujhe aapka signal mil gaya hai."

Ab connection successfully established ho jata hai aur data transfer shuru ho sakta hai.

### 3. HTTP/1.1 (1997-1999) - The Standard

Ye aaj bhi internet ka ek bara hissa chala raha hai.

- **Persistent Connections:** Ek hi connection par multiple files mangwai ja sakti hain (Keep-Alive).

- **PUT, DELETE, OPTIONS, PATCH** jaise methods add huye.

- **Caching** aur **Virtual Hosting** ka support aya.

- **Drawback:** "Head-of-Line Blocking" ka masla tha—agar ek request slow ho jaye, to uske peeche wali sari requests ruk jati thin.

### 4. HTTP/2 (2015) - Performance Focus

Google ke SPDY protocol par mabni ye version speed ke liye laya gaya tha.

- **Binary Protocol:** Data text ke bajaye binary format mein jata hai, jo machine ke liye tez hai.

- **Multiplexing:** Ek hi connection par parallel mein bohot saari requests aur responses bheje ja sakte hain (HOL blocking khatam hui).

- **Server Push:** Server khud hi zaroori files (CSS/JS) client ko bhej deta hai bina mange.

### 5. HTTP/3 (2022) - The QUIC Era

Ye sabse modern version hai jo TCP ke bajaye **UDP** par chalta hai (QUIC protocol ke zariye).

- **Zero Latency:** Connection setup bohot fast hota hai.

- **Mobility:** Agar aapka network switch ho (Wi-Fi se Mobile Data), to connection drop nahi hota.

- Ye purane protocols ki sari kamzoriyon (congestion control) ko behtar karta hai.
