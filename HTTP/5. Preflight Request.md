## Preflight Request

The request made by the web browser to the server to inquire some details from the server before making the actual request.

Let say server want to know is this particular header is allowed by the server or not, or is this HTTP method is supported by the server or not.

Let see when a browser is likely to make a Preflight request.

### 1. HTTP Methods (Non-Simple)

Agar aapka request method **Safe/Simple** list mein nahi hai:

- **Simple Methods:** `GET`, `POST`, `HEAD`.

- **Triggers Preflight:** `PUT`, `DELETE`, `PATCH`, `CONNECT`, `OPTIONS`, `TRACE`.

### 2. Request Headers (Custom/Non-Simple)

Agar aap aise headers bhej rahe hain jo browser default list mein nahi hote:

- **Triggers Preflight:** `Authorization` (JWT ke liye), `X-Custom-Header`, `X-API-KEY`, wagera.

- *Note:* Sirf standard headers jaise `Accept` ya `Language` preflight trigger nahi karte.

### 3. Content-Type Restrictions

Agar aapka Contetn-Type header ki value standard HTML form format se alag hai:

- **Simple Types:** `application/x-www-form-urlencoded`, `multipart/form-data`, `text/plain`.

- **Triggers Preflight:** **`application/json`** (Sab se common wajah), `application/xml`, etc.
