## Prefix

The `++` or `--` symbol is placed before the the variable. The operation (increment or decrement) is performed before the value of the variable is used in the expression.

```js
let x = 5;
let y = ++x; // 6
```

The value of x is assigned to y after incrementing (6) the x.

## Postfix

The value of the variable in the expression is used before performing the increment or decrement operation.

```js
let x = 5;
let y = x++; // 5
```

The value of x is assigned to y before incrementing (5) the x.
