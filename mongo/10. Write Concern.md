## Write Concern

Yeah apki help karta hey configure karney mey k app ko write operation k acknowledgement  kab di jaye, esa environment jaha apke pass mongo servers ka aik replica set ho.

## What is replica?

An extra copy of the primary server is called a replica of the primary database which is used as backup in case the primary server faild.

## What is a replica set?

Set of multiple copies of the primary server having the same data as primary server called the replica set.

## Why write concern?

Jab app k pass replica set hota hey to kai dafa app chatey heyn apko tabhi acknowledged kia jaye aik write operation k barey mey jab data primary server or sarey replicas mey write ho jaye, to configure this behavior you can configure write concern.

```mongodb
db.countries.insertOne(
  { _id: "PK", name: "Pakistan" },
  { writeConcern: { w: "majority" } }
);
```

Yani jab majority replicas mey data write ho jaye tabh acknowledged karo.

But if you run:

```mongodb
db.countries.insertOne(
  { _id: "PK", name: "Pakistan" },
  { writeConcern: { w: 1 } }
);
```

That mean k jab data primary server mey write ho jaye tabh acknowledged karo

But if you run:

```mongodb
db.countries.insertOne(
  { _id: "PK", name: "Pakistan" },
  { writeConcern: { w: 0 } }
);
```

The `0` mean to client is don't wait for the acknowledgedment.

But if you run: 

```mongodb
db.countries.insertOne(
  { _id: "PK", name: "Pakistan" },
  { writeConcern: { w: numberOfServers } }
);
```

That mean yaha appke pass jitnay bhi total servers unka count do or jab un sarey servers write operation complete ho jaye tabh acknowledged karo.
