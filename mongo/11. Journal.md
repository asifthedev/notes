# Journal

Mongodb Server ka storage engine data ko by default RAM mey write kar k hamey acknowledged kar deyta hey because writing on RAM is faster.

And after that data ko permanently database file mey disk k uper write kia jata hey.

Now let say data RAM mey store huwa or server crash kar giya ya phir restart honey lagiya to RAM wala data to wiped out ho jaye ga, that mean there is no way k data ko recover kar permanently write kia jaye.

Yahi per ata hey `Journal` data ko RAM k sath is Journal k ander bhi write out kia hey as TO DO for operation to perform later it's quicker then writing in actual.

Ager server crash bhi hota hey ya restart hota hey to jo bhi write ya update operation pending hoga usko is journal ki help say pora kia jata hey.

By default journal is undefined that mean k journal mey operation ko wirte out nahi kia jata but you can enable it.

```mongodb
db.countries.insertOne(
  { _id: "PK", name: "Pakistan" },
  { writeConcern: { w: 1, j: true } });
```

**NOTE**

Writing data with journal `true` is secure but become little slower.
