# Atomicity

In database context atomicity ka mtlb hey aik transaction ya to fully complete hogi ya phir fully fail ho jaye gi, there's no partial completion.

Mongodb k ander atomicity document level k uper guarantee di jati hey, yani koee bhi operation aik single document k uper (insert, update, delete) ya to successful hoga ya phir fail there's no partial completion.

```mongodb
db.users.insertOne({_id: 1, name: "Asif", age: 21})
```

Ager yeah document write ho raha tha or `id` or `name` write honey k baad ager server crash ho giya to restart honey per mongodb id or name ki insertion ko rollback kardeyga.

## Confusion

Dont's confuse atomicity with ordered and unordered insertion, because atomicity is something related to single document.

Orderd insertion ka mtlb `insertMany()` ager aik operation midway kis reason say fail ho jata hey to jo documents successfully insert ho chukay hongay woh rollback nahi hongay.

And Unordered insertion ka mtlb hey k sirf wahi document insert nahi hoga jo faulty hey baki sarey document insert ho jaye gay.
