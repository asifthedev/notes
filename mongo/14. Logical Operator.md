# Logical Operator

Used to filter documents by combining multiple conditions.

## $and

Jido ditiya hoeya sariya conditiona true evaulate hon giya tabhi document ko return kiya jaye.

```mongodb
db.students.find({$and: [{age {$gt: 20}}, {cgpa: {$lte: 3}}]})
```

## $or

Jab di gayi sari coditions mey say koee aik bhi condition true ho to document ko return kardo.

```mongodb
db.students.find({$or: [{department: "IT"}, {department: "CS"}]})
```

Ager student k department IT ho ya CS ho yani dono mey aik to us document ko utha lo or user k mu per maro 😂.

## $nor

Ager di hoee sari conditions k opposite ho yani ulat ho yani di hoee sari conditions jaha per false evaluate ho rahi ho us document ko display karo.

```mongodb
db.students.find({$nor: [{department: "IT"}, {department: "CS"}]})
```

Yani esa student ko dhikao jis ka deparment na to IT ho na hi CS ho. As I told you where all of the given conditions evaluate as false then only $nor operator will return true.

## $not

It's kind of like $nor operator but it only check for a single condition. 

```mongodb
db.products.find({inStock: {$not: {$eq :true}}})
```

Jaha per bhi inStock na ($not) equal ho (\$eq) true k (yani false ho) woh document return karo.

## How to combine multiple logical operators?

```mongodb
db.products.find({
  releaseDate: { $gte: ISODate("2022-01-01") },
  inStock: true,
  category: { $ne: "Clothing" },
  $or: [
    { rating: { $gte: 4 } },
    { price: { $lte: 20 } }
  ]
})
```
