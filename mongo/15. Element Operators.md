# $type Operator

**Purpose:**  
Matches documents where a field is of a specific BSON data type.

**Syntax:**

```js
{ field: { $type: <typeNumber or typeString> } }
```

**Examples:**

```js
{ price: { $type: "double" } }
{ name: { $type: 2 } }   // 2 = string
```

**Use case:**  
Check if a field has the correct data type before processing.

# $exists Operator

**Purpose:**  
Checks whether a field exists in a document.

**Syntax:**

```js
{ field: { $exists: true } }
{ field: { $exists: false } }
```

**Examples:**

```js
{ warranty: { $exists: true } }   // field must be present
{ discount: { $exists: false } }  // field must be missing
```

**Notes:**

- `$exists` checks only for presence, not value.
- A field with `null` still counts as existing.
