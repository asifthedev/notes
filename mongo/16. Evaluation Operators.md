# Evaluation Operators

## $mod

As we the modulous operator is used to retrun remaindor. Here it's used to divide the value of field of a document with the given number and if the remainder of this division is equal to your given value then only return the document.

```mongodb
db.products.find({price: {$mod: [5, 0]}})
```

Ager price 5 say pora pora divisible hey or remainder zeor aa raha he to document return karo.

## $regex

It is used to search through documents using a regular expression.

```mongodb
db.students.find({name: {$regex: /^Asif/}})
```

Woh student dhikao jiska name Asif say start ho raha ho.

## $expr

**Question 01**

Find all products where the sale price is GREATER than the regular price

```mongodb
db.products.find({$expr: {$gt: ["$salePrice", "$regularPrice"]}})
```

**Question 02**

Find products where available stock (stock - reserved) is below minimum stock

```mongodb
db.products.find({
  $expr: {
    $lt: [
      { $subtract: ["$stock", "$minStock"] },
      "$reserved"
    ]
  }
})
```

**Question 03**

Find orders where the total amount exceeds the customer's credit limit

```mongodb
 db.orders.find({$expr: {$gt: ["$total", "$creditLimit"]}})
```

**Question 04**

Find bank accounts where the balance is below the minimum balance

**Question 06**

Find students whose average score (math + science + english / 3) is above their target

```mongodb
db.students.findOne({
  $expr: {
    $gt: [
      {
        $divide: [
          { $add: ["$mathScore", "$scienceScore", "$englishScore"] },
          3,
        ],
      },
      "$targetAverage",
    ],
  },
});
```

**Question 07**

Find properties where monthly profit rent - expenses is greater than 1000

```mongodb
db.properties.find({
  $expr: {
    $gt: [{ $subtract: ["$monthlyRent", "$monthlyExpenses"] }, 1000],
  },
});
```
