# Array Operators

These are the operators used to manipulate array.

## $all

Find documents where array contains all specified elements.

```mongodb
db.students.find({
  courses: { $all: ["Math", "Physics"] }
});
```

Find students who have both "Math" and "Physics" courses.

## $size

Find arrays with specific length

```mongodb
db.students.find({courses: {$size: 4}})
```

Find students with exactly 4 courses

## $elemMatch

Yeah operator tabh use hota hey when you have an **array of objects**  and you need to apply **multiple conditions** to **one element** inside that array

Think of it like saying:

“Find documents where **one single array element** meets **all** these conditions.”

Yani ager array k ander multiple document type k elements hey to ager aik single document element di hoee sari conditions k match karta hey to us documet ko return karo.

Without `$elemMatch`, MongoDB might match conditions across **different** elements — which is often NOT what you want.

Suppose you have documents like:

```mongodb
{
  name: "Asif",
  scores: [ 
            { subject: "Math", marks: 85 },
            { subject: "English", marks: 92 } ]}
```

**Query:** Find students who scored **Math > 80**

```mongodb
db.students.find(
    {score: {$elemMatch: {subject: "Math", marks: {$gt: 80}}})
```

This ensures **the same element** has both:

- `subject: "Math"`
- `marks > 80`
