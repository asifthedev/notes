## Project

Jo project aik object hota hey `find()` method k ander jo apko aik collection say documetn ko read kartey wakt yeah controle karney mey help karta hey k kon say field har document k ouput mey show honey chaye or kon say nahi.

Let say apka document kuxh esa dhikta hey

```mongodb
{
    _id: 1
    name: "Asif",
    age: 22,
    height: "5/4"
    weight: "54KG"
}
```

And you want to only show name and age in ouput while reading from a collection, to apko project object k ander jo field show karney heyn unka agay `1` likh do.

```mongodb
db.user.find({}, {name: 1, age: 1})
```

Now mongo will only show you these two fields only in each doucment, baki fileds nahi najar ayegay. the empty brackets `{}` means I want to read all documents from users collection.

```mongodb
// output
{
    _id: 1
    name: "Asif",
    age: 22
}
```

**NOTE**: Jin field ko mention nahi kia jaye ga  woh nahi show hongay yani `name` and `age` k illawa baki koee field show nahi hoga except the `_id` field.

Ager `_id` field ko bhi remove kar chahtey hey to app usay:

```mongodb
db.user.find({}, {name: 1, age: 2, _id: 0})
```

Now will not show the `_id` the id field.

## Project Nested Documents

Let say you have this document:

```mongodb
{
  _id: ObjectId("673f60e271bf64a76286b031"),
  name: "John Doe",
  age: 32,
  skills: [
    { name: "tester", level: 6 },
    { name: "designer", level: 3 }
  ],
  hobbies: [
    "sports",
    "music",
    "reading"
  ]
}
```

And you oly want to show name of the skill in skills array for each document inside array let see how can we do that.

```mongodb
db.employees.find({}, {_id: 0, name: 1, "skills.name": 1})
```

**Output**

```mongodb
{
  name: "John Doe",
  skills: [
    { name: "tester" },
    { name: "designer" }
  ]
}
```

## Projecting only the desired element of an array

Let say we hav the same employee doucment again:

```mongodb
{
  _id: ObjectId("673f60e271bf64a76286b031"),
  name: "John Doe",
  age: 32,
  skills: [
    { name: "tester", level: 6 },
    { name: "designer", level: 3 }
  ],
  hobbies: [
    "sports",
    "music",
    "reading"
  ]
}
```

And you want the employees who has `music` as their hobby, easy right?

```mongodb
db.employees.find({hobbies: "music"}, {_id: 0, name: 1, hobbies: 1})
```

Now you will have the output of the above code snippet like this:

```mongodb
{ name: 'John Smith', hobbies: [ 'sports', 'music', 'cooking' ]
```

But you only want to show the `music` hobby or the hobby you are filtering with, or baki sari hobbies show na ho, to app is cheez ko karnay kelye `$` operator ka use kar saktey ho.

 _The `$` symbol returns only the array element that matched the query condition._

```mongodb
db.employees.find({hobbies: "music"}, {_id: 0, name: 1, "hobbies.$": 1})
```

Ouput:

```mongodb
{ name: 'John Smith', hobbies: ['music']
```

To abh baki k element in hobbies array show nahi ho rahey.

## $slice

MongoDB `$slice` is used inside a projection object to return only a portion of an array. It helps reduce the size of the response when arrays are large or when you only need a preview of the data.

Only get first two elements of an array

```mongodb
db.products.find(
  {},
  { name: 1, reviews: { $slice: 2 } })
```

To skip items and then return a limited range in the example given below skip the first elemetn at 0 index and return two elements starting form 1 index inclusive.

```js
db.products.find(
  {},
  { name: 1, reviews: { $slice: [1, 2] } })
```

`$slice` works only in projection and cannot be used to modify documents. It’s useful when you need only a portion of an array, like previewing top reviews, latest logs, or limiting heavy array fields.
