# Updation Operators

Let's learn how to update doucments using update operators. Those are operators used in `updateOne()` and `updateMany()` 

## $set

It's used to add a new field or update the existing value of an existing field. Let's change the existing price of a product who's id is one.

```mongodb
db.products.updateOne({_id: 1}, {$set: {price: 100})
```

**How to update multiple fields using set operator?**

```mongodb
db.products.updateOne({_id: 1}, {$set: {price: 100, salePrice: 80}})
```

**How to add a new field in a document?**

```mongodb
db..collectionName.updateOne({_id: 1, })
```


## $min

If the value you provide is **less than** the current field value, MongoDB updates it.  
If it’s greater, MongoDB ignores it.

```mongodb
db.students.updateOne(
  { _id: 1 },
  { $min: { score: 50 } }
)
```

- If current `score` is **60**, it becomes **50**
- If current `score` is **40**, it stays **40**

## $max

If the value you provide is **greater than** the current field value, MongoDB updates it.  
If it’s smaller, MongoDB ignores it.

```mongodb
db.students.updateOne(
  { _id: 1 },
  { $max: { score: 80 } })
```

- If current `score` is **70**, it becomes **80**
- If current `score` is **90**, it stays **90**

## $unset

The `$unset` operator **removes a field** from a document.

- It **does NOT** delete the entire document
- It **does NOT** set the field to `null`
- It **completely removes** the key from the document

```mongodb
db.users.updateOne(
  { username: "asif" },
  { $unset: { age: "" } }
)
```

The `age` field is **deleted** from the document

**Remove Multiple Fields**

```mongodb
db.users.updateOne(
  { username: "asif" },
  { $unset: { age: "", address: "", phone: "" } }
)
```

## Upsert

Upsert = Update + Insert
When performing an update operation, if no document matches the query filter, MongoDB will insert a new document instead of doing nothing.

You enable this behavior using:

```mongodb
{ upsert: true }
```

Example:

```mongodb
db.users.updateOne(
  { username: "asif" },
  { $set: { age: 25 } },
  { upsert: true }
)
```

If no user named `"asif"` exists, MongoDB inserts:

```mongodb
{
  _id: ObjectId(...),
  username: "asif",
  age: 25
}
```

## $rename

The `$rename` operator **changes the name of a field** in a document.

- Old field → New field
- The **value stays the same**

```mongodb
db.collection.updateOne(
  { _id: 1 },
  { $rename: { oldFieldName: "newFieldName" } }
)
```

**Example:**

```mongodb
db.users.updateOne(
  { username: "asif" },
  { $rename: { fullName: "name" } })
```
