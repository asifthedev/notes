# MongoDB Cursor / Pointer

### Cursor kya hota hai?

Cursor ek **pointer** hota hai jo result set ka subset hota hey yani yeah MongoDB query ka result **step-by-step** return karta hai.

### 2. Cursor kyun use hota hai?

Agar data bohat zyada ho, MongoDB saara data aik sath nahi bhejta, isay network bandwidth ziyada use hogi or RAM and other compute ka intensive use ki wajah say sytem freeze ya hand ho jaye ga. 
Cursor se data **thoda-thoda** karke milta hai, jis se memory overload nahi hoti or network bandwidth bhi kam use hoti hey

### 3. Cursor kab milta hai?

Jab bhi aap `find()` query chalate ho, or app k collection k ander 20 say ziyada document hotey heyn to MongoDB pehlay 20 documents ko as **cursor** object return karta hai, not sara data directly.

Example:

If you have more than 20 doucments inside your collection, and if you run:

```mongodb
db.students.find()
```

It will return you only first 20 documents as cursor object and as at the end you'll see:

```mongodb
[
  {_id: 1, name: "Asif", marks: 78}
  {...}
  { _id: 19, name: 'Nimra', marks: 58 },
  { _id: 20, name: 'Adil', marks: 84 }
]
Type "it" for more
```

If you type `it` it will iterate over to the next cursor.

## **next()**

The next function is used to iterate over a batch of documents one by one return in one cursor and as this the number of document inside a cursor is completed it moves on the next cursor.

At a time the `next()` will return back only a single document. If you run this code given below it will return you back first document.

```mongodb
db.students.find().next()
```

However if you run this code more than once, you will always get **the first document**. Why?  Because **every time you run this line, you are creating a brand‑new cursor**.  
A new cursor always starts at the beginning of the result set, so `next()` returns the first document again.

To actually iterate through documents, you must **store the cursor**:

```javascript
let cursor = db.students.find();
cursor.next(); // first document
cursor.next(); // second document
cursor.next(); // third document
```

Now the cursor maintains its position and moves forward with each call to `next()`.

## **forEach()**

Yeah code pehlay batch mey majood har document ko iterate karey ga phir aglay batch ya cursor ko load karey ga or usay iterate karey ga.

```js
db.users.find().forEach(doc => print(doc))
```

## **toArray()**

We can also use, `toArray()` it will automatically iterate over all the cursors and return an array of all documents. 

```mongodb
db.users.find().toArray()
```

### 5. Cursor ka simple meaning:

- Cursor = **Query result ka pointer**

- Data = **line-by-line** milta hai

- Large data = **smooth** milta hai

- Memory = **save** hoti hai
