# Querying Data from Multiple Collections

When you store related data using refrencing approach where documents in one collection have id as refrence to documents stored in an other collection.

In that scenario you want to look at the actual document whos id referred, that is where we use the `$lookup` aggregate operator.

Let say hamray pass aik order document hey:

```mongodb
{
    _id: 1,
    amount: 100,
    productId: 102 
}
```

Now you want to know which product has been purchased from `products` collection who's id is 102 for that we can run this pieces of code:

```mongodb
db.orders.aggregate([
  {
    $match: { _id: 1 }   // only the order with id = 1
  },
  {
    $lookup: {
      from: "products",
      localField: "productId",
      foreignField: "_id",
      as: "product"
    }
  }
])
```

**from** 

Konsi collection hey jisay mey say referred data hey, in our case it's products collection jis k ander data majood hey jisay ham read karna cha rahey heyn

**localField**

Yani konsa local field jis k ander refrence store hey

**foreingField**

Yani referred collection ka konsa field hey jisko local field k sath match karna hey or ager woh match ho jaye to us document ko dhika deyna hey.

**as** 

As mey ham batatey heyn jo record millay geyn unka name kia hoga asal mey yeah aik array hota ho jis k ander sarey referred documents hotey heyn.
