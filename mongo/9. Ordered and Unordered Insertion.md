# Type of insertion

There are two type of insertion and it's truely worth understanding them, or yeah specifically  `insertMany()` method k realted hey

1. Ordered insertion

2. Unordered insertion

## Orderd Insertion

Jab app `insertMany()` k zariye document ko insert kartey ho to jo har document standalone yani akeyla process kia jata hey.

Ager koee document k insert kisi bhi reason say fail hoti hey to usay pehlay jitnay document insert ho chukay honey woh rollback nahi hongay balkey woh database mey inserted hi rahey gey

Or faulty document k baad waley document ki insertion ko abort kar diya jaye ga even ager woh faulty na bhi ho, yeah hoti hey orderd insertion

For example app ney pehli dafa yeah documents ko insert kia.

```mongodb
db.countries.insertMany(
  { _id: "PK", name: "Pakistan" },
  { _id: "IN", name: "India" },
  { _id: "UK", name: "United Kingdom" });
```

Now if you try to insert:

```mongodb
db.countries.insertMany(
  { _id: "USA", name: "United States of America" },
  { _id: "IN", name: "India" },
  { _id: "BD", name: "Bangladesh" }
);
```

Mongodb do same id k documents ko allowed nahi karta per ager ham dehkay to `IN` ki id say pehlay hi aik record majood hey or ham dobara insert karney ki try kar rahey heyn jo k error through karey ga.

Abh error through honey say pehlay jo documetns insert ho chukay hongay woh rollback nahi hongay yani the document with id `USA` successfully insert ho jana hey.

But the document with id `DB` woh insert nahi hoga even k woh faulty nahi hey, to yahi hoti hey ordered insertion.

## Unordered Insertion

Let say ager chahtey k sirf faulty document in insert na ho baki sarey documetn insert ho jaye or hona bhi esay hi chayee.

In that case app ordered insrktion ko false set kar saktey heyn esa karney say even koee document faulty bhi hey to sirf usi insertion fail hogi baki insert ho jaye gay.

```mongodb
db.countries.insertMany(
  [
    { _id: "USA", name: "United States of America" },
    { _id: "IN", name: "India" },
    { _id: "BD", name: "Bangladesh" },
  ],
  { ordered: false }
);
```

Abh sirf India ki insertion nahi hogi baki do documetns insert ho jaye gay, yahi hoti hey unordered insertion.
